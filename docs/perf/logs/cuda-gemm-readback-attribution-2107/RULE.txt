[実行方法]

  crates/backend-cuda/src/readback_attribution_diag_tests_2107.rs を
  `--ignored --exact <test> --nocapture --test-threads=1` で起動し、
  出力は JSONL（プレフィックス DIAG_JSON）。
- N = 1024 / 2048 / 4096。腕 = clone_dtoh_legacy_to_vec /
  clone_dtoh_borrowed_keep_alive / clone_dtoh_borrowed_dummy_alloc_free /
  pretouched_fresh_split の 4 腕 + 補助対照 pretouched_fresh_production。
- run1〜run5 の 5 run。run ごとに腕の実行順を巡回させる。
  差し替え・追加起動・既存 run ファイルの上書きはしない。
- 1 プロセスあたり warmup 20 + 計測 20 試行。単位は μs。

[同一セッション Layer A]
- 同じセッションで bench-fandhe --task gemm --device cuda --mode reuse --phases
  （fandhe-ai =0.9.0 ピン・既存コマンド）を N ごとに 5 run 実行する。
- 計測時点で Layer A（fandhe-ai =0.9.0）と Layer B（HEAD）の計測経路が同一で
  あることを check_layer_a_path_identity.py（orchestrate.sh が呼び出し）で確認し
  env_info.txt の layerA_same_code と項目別 path_item 行に記録する。比較対象は
  Layer A が通る経路の項目（gemm.rs の検証・tile 選択〈TILED_PIPELINE_128X64_*

  readback 系と READBACK_DEST）で、コメント行と診断 feature ゲート項目〈および本番
  既定で到達しない ReadbackDest::Fresh 腕〉を除いた正規化テキストの完全一致を要求する。
  計測経路項目の差分は no、抽出不能は unknown となる。生成・起動経路の項目
  （CudaGemm::new・compile_tiled_pipeline*・launch_tiled_f32・Layer B が実際に呼ぶ
  launch_tiled_f32_pooled・module_cache.rs::load_function_cached 等）の差分・抽出不能は
  unknown となる（下記「追記」の人手レビュー済み既知差分を除く）。yes 以外は
  帰属判定は「無効（参考扱い）」とする。ファイル全体の差分は判定に用いない。

[代表値]
- 各区間は run ごとの median（20 試行）を採り、5 run 間の中央値と min-max を報告する。

[checksum 規則（hard・fail-closed）]
- 各 (N, 腕) で全 run の checksum_bits が一致すること。
- 同一 N の全腕（補助を含む）で checksum_bits が一致すること。
- Layer A の checksum が既知値（N=1024 -1855.597736 / N=2048 -6016.774008 /
  N=4096 -25768.747284。§12.3）と一致すること。
- 1 件でも不一致なら系列は無効（集計は exit != 0）。

[帰属の定義（同一セッションの値のみ）]
- residual = LayerA.matmul - Sum_matmul_equiv(clone_dtoh_borrowed_keep_alive)
  （Sum_matmul_equiv = h2d_a+h2d_b+alloc_c+launch_issue+kernel_wait+readback。host_read を除く）。
- alloc_fill_share = (pretouched_fresh_split.dest_alloc + pretouch_fill) / residual
  - >= 0.80 : 宛先確保・事前タッチへの帰属を支持
  - <  0.50 : 棄却（主因は別）
  - それ以外: 未確定
  - residual <= 0: 未説明分非再現。帰属は行わない
- 補助指標（記録のみ）:
  gap_ratio = Sum_matmul_equiv(pretouched_fresh_split) / LayerA.matmul、
  clone_dtoh 腕の readback - pretouched_fresh_split の (d2h_issue+d2h_sync)。

[計装健全性（record_only）]
- |(dest_alloc+pretouch_fill+d2h_issue+d2h_sync) - pretouched_fresh_production.readback_total|
  <= 5% x readback_total を記録する。超過時は帰属判定に「分解歪みあり」を付記する。

[非後退（record_only）]
- ratio = pretouched_fresh_split.sum_readback / clone_dtoh_legacy_to_vec.sum_readback
  を記録する。本イシューは本番修正を出荷しないため採否ゲートにしない。
- N=4096 の clone_dtoh 二峰性（§12.4）は q1/q3/min/max の記録のみ。

[専有ゲート]
