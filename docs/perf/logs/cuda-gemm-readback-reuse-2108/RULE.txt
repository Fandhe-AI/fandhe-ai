[計測]
- 5 round 固定（AB_ROUNDS=5 以外は拒否）、プロセス独立起動、round ごとに起動順を反転（run_ab_readback_reuse_cuda.sh）
- run の差し替え・追加起動はしない。同一 label の既存出力があれば停止する
- 各セルの ratio = median(after) / median(before)（5 run の中央値どうし。単位は bench-fandhe の median_s）

[判定]
- ADOPT: 専有ゲート（AB_LOAD_GATE_MODE=exclusive。load1 < 1.0 かつ GPU 使用率 0% を 3 サンプル連続）を通過し、
  前提ゲートで対象となった全判定セルで ratio <= 1.00（--threshold 1.00）、かつ全 run で checksum 完全一致
  （--require-checksum-exact）。checksum 不一致は fail-closed
- REJECT: 専有ゲートが成立した系列で、いずれかの判定セルが ratio > 1.00、または checksum 不一致
- undetermined: 専有ゲート不成立・record_only・取得不能・前提ゲートが支持でない N を含む場合（ADOPT にしない）
- しきい値を事後調整して再計測しない

[事前表明する期待値]
- 仮説 H-reuse（pageable 宛先の D2H・事前フィルを pinned 直接 DMA + copy-out 1 回へ置換すると露出コストが減る）は
  未検証。copy-out の memcpy（N=4096 で 64 MiB）が追加されるため、大形状では改善しないか後退しうる。
  ADOPT の見込みは高くない。REJECT／undetermined でも機構（既定 OFF）と記録を残す

[ADOPT 時]
