## R4 採用候補（しきい値以上の全格子点が 5/5 run で SME>=NEON となる極小の組）

- `min(m,n) >= 256` かつ `k >= 128`
- `min(m,n) >= 512` かつ `k >= 32`

現行定数 `SME_MIN_M/N=256`・`SME_MIN_K=64` は本集計では変更しない（本番切替は #1979 のユーザー承認事項）。
