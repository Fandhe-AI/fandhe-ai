判定（判定契約は各テストのコードが定める。ここでは変えない）:
  2 は Metal 指定テープと NaiveOps ホストテープの bit 完全一致。ほか（1・3〜6）は REQ-2 統一複合判定
  （相対誤差 1e-3 未満 または 絶対誤差 1e-5 未満。tolerance 定数・baseline は不変）。
  pass: exit 0 かつ "running 1 test" かつ "test result: ok. 1 passed; 0 failed"。
  fail: 1 件以上のテスト失敗。tape_for(Device::Metal) の失敗や Unsupported を含む。
    Metal と CPU は自前バックエンド同士の比較なので判定不能にせず通常の parity 失敗として扱う。
    2 の bit 不一致はそのテスト自身の bit 一致契約の fail として記録し、ただちに REQ-2 違反とはみなさない。
  undetermined: ノード到達不能、ビルド不能、--list で選ばれた件数が 1 でない。
  時間計測ではないので中央値は取らない。テストごとの pass／fail の件数で記録する。
