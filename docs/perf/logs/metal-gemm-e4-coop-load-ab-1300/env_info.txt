## 解釈上の注意（環境ノイズ）
- 上記負荷状況が示すとおり、本機は計測期間を通じて他セッションと共有された
  状態だった。個々の run のログで q3（第 3 四分位）が中央値の数倍に達する
  ケース（例: N=1024 run1 の L0-P8 は q1=0.6025・median=1.0289・run3 では
  q1=0.3240 など、run 間で q1 が大きくばらつく）が見られ、環境負荷の変動が
  トレイル単位で計測値に混入していることを示す。5 run 中央値の中央値
  （aggregate.md）と run 単位の符号一貫性の両方を判断材料とした
  （§11.4 参照）
