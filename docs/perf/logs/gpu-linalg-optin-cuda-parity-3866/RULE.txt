# ---- 判定（事前宣言）----
judgment:
  各ケース: assert_parity（相対誤差 1e-3 未満 または 絶対誤差 1e-5 未満。fail_count=0 が必要）と、被検腕の出力がすべて有限であること
pass: コマンドが exit 0 で、出力に「running 1 test」と「test result: ok. 1 passed; 0 failed」があること
fail: 上記以外の非 0 終了のうち undetermined に当たらないもの。assert_parity の「複合判定 FAIL」、「非有限値が出力された」、
  「Unsupported（デバイス経路に入っていない）」（facade のゲートがデバイス経路に入れていない＝被検対象の不成立）、det の bit 不一致、
  演算の expect の panic を含む
undetermined: ノードに届かない、ビルドできない、timeout、--list の不一致、実機ロックの取得不能・喪失、
  出力に「CUDA 実機が必要」（tape_for の expect）がある非 0 終了。pass として扱わない
completion: 6 本すべて pass で GB10 側の完了とする。#3866 の Closes は Mac mini 側（同 PR の ../gpu-linalg-optin-metal-parity-3866/RULE.txt）も
