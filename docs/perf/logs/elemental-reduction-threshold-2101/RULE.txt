事前登録判定規則（イシュー #2101・Phase 0＝しきい値候補の決定。実測より前に固定する）
=====================================================================

対象: crates/backend-cpu/src/reduction.rs の rayon fork-join サイト
      （逐次フォールバック機構。ゲート REDUCTION_SEQUENTIAL_FALLBACK_ENABLED=false が既定）
除外: mse_loss_backward（#1578 で REJECT 確定。同型の再実行はしない）

計測コマンド（機体ごとに 5 プロセスを独立に起動。RAYON_NUM_THREADS は未設定＝本番と同一）:
  cargo test -p fandhe-ai-backend-cpu --release --lib \
    reduction::tests::reduction_threshold_sweep -- --ignored --nocapture

対象演算: sum(dim=None)・sum(dim=Some 0 / Some 1、shape [64, n/64])・max(dim=None)・mean(dim=None)
サイズ: n in {640, 2560, 4096, 8192, 16384, 32768, 65536, 131072, 262144}（#1578 Phase 0 と同系列）
腕: forced-seq と forced-par。(n, 腕, 演算) ごとに 1000 反復の中央値(ns)と checksum を出力する。

代表値: プロセスごとの中央値の、5 プロセスにわたる中央値。 r(n) = seq / par。

checksum: 全セルで seq と par が完全一致すること。1 件でも不一致なら機構の不具合として
          FAIL とし、性能判定の前に止める。

決定規則（共通しきい値 T が許す性能後退を「セル単位で」定め、全セルで検証する）:
  - セル = (機体, 演算, n)。演算は sum(None)・sum(Some 0)・sum(Some 1)・max(None)・mean(None) の 5 種。
    しきい値 T 未満は逐次腕・T 以上は並列腕になる。
  - 後退の定義: T 未満のセル（n < T）で並列腕の方が速い（r(n) = seq / par > R_MAX）こと。
    T 以上のセルは既定と同じ並列腕のままなので後退は生じない。
  - 許容: R_MAX = 1.05（プロセス間中央値のノイズ幅。事前固定。全セル共通で演算・機体別には変えない）。
    T 未満のどのセルも後退させない（r(n) <= R_MAX が全セルで成立すること）。
  - 各 (機体, 演算) の違反点 v = 「r(n) > R_MAX となる最小の n」（無ければ 1<<18）。
    T = 全 (機体, 演算) の v の最小値（演算間の最大・平均・中央値・多数決や機体間 max は採らない。
    最大を採ると、より小さい n で並列腕が速い演算が最大値未満の範囲で遅い逐次腕に固定される）。
    これにより T 未満の全セルで r(n) <= R_MAX が構成上保証され、その保証は対象サイズ系列上の全セルで
    生ログから機械的に再検証できる（検証手順: T 未満の全セルを列挙し max r(n) <= R_MAX を確認する）。
  - 上記は対象サイズ系列上のセルに限る。系列外のサイズでの挙動は主張しない。
  - T <= 640 なら REJECT（小形状で逐次腕の効く範囲がない）。
  - それ以外は T を #2102 の A/B 候補値として渡す。
  - 逐次腕が速いセルの利得（r(n) < 1）の大きさは本規則では判定に使わない（後退なしの確認のみ。利得の判定は #2102）。

負荷: record_only（load average の推移を env_info に記録）。専有ゲートは #2102 の A/B 側で適用する。
事後緩和・セル除外・run の追加による再判定は行わない。
本規則は Phase 0（しきい値候補の決定）に限る。framework-compare 全セルの非後退判定
（ratio <= 1.00）は #2102 の範囲。
