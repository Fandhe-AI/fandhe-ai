指標（#3672 の RULE.txt・RULE.v2.txt の定義をそのまま使う）:
- ratio_r = after_r / before_r（同じ run 番号の対）。セルの ratio は 5 個の中央値。

- X(arm) = resident_public.iter_total - gemm_device_hold.iter_total（N=4096・GB10・run ごと→5 run 中央値）
- DL_before = before 木の resident_split の phase=download の 5 run 中央値（N=4096・GB10）
- rho_REM = (X_before - X_after) / DL_before、rho_BENCH = (bench_iter_before - bench_iter_after) / DL_before、
  rho_OFFSET = 1 - rho_BENCH。rho_REM のみ ADOPT 条件、他は記録のみ。
  rho の計算に経路外の腕（gemm_device_hold・resident_split）の区間を使うことは、セルの判定ではないので妨げない。

判定（閾値は #3672 と同値。緩めない）:
- ADOPT: 処置 2 セルとも中央値 ratio <= 0.95 かつ 5/5 run で ratio < 1.00、rho_REM >= 0.5、
  経路上の非処置セルがすべて中央値 ratio <= 1.00、checksum 全件一致、両機体の系列が揃いゲート pass
- REJECT: 経路上のセルに 5/5 run で後退（全 run で ratio > 1.00）がある／処置セルの中央値 ratio > 1.00／
  checksum 不一致が 1 件でもある
- checksum の範囲は絞らない（診断の全 8 腕 × 5 N の iter_total と bench の 5 N）。正しさの検査で経路と無関係のため。
- 判定不能: 上記のいずれにも当たらない。片機体が未実測・record_only なら ADOPT は出さず
  「判定不能（未実測あり）」とし、REJECT 条件に当たる場合のみ REJECT を出す。
- ADOPT・REJECT・判定不能はいずれも正当な結果として記録する。
- 経路外セルは判定に使わず、次を記録する: 中央値 ratio・run ごとの ratio・5/5 run で ratio > 1.00 の件数・
  5/5 run で ratio < 1.00 の件数。差が無い場合の期待件数（1 セルあたり 1/32）× セル数を並べて載せる。
