[手順]
- 5 round 固定（AB_ROUNDS が 5 以外なら拒否）。プロセスは独立起動。round ごとに before／after の起動順を反転。run の差し替え・追加起動・セル除外はしない。同じラベルの既存出力があれば停止。RAYON_NUM_THREADS は unset。

[比]
- ratio = median(after 5 run の median_s) / median(before 5 run の median_s)
- ratio_r = after_r / before_r（r は JSONL の行順 = round 順）

[hard 条件（全セル）]

- 更新後パラメータの PARAM_DIGEST が全 run・両腕で同値。欠落は不一致として扱う。
- 不一致は該当セルを REJECT（正しさの失敗）とし、#3246 の不具合として所有者へ報告する。ゲート判定より先に適用する。

[判定（処置セル）]
- ADOPT: ratio <= 0.95 かつ 5/5 round で ratio_r < 1.00。
- REJECT: ratio > 1.00、または 5/5 round で ratio_r > 1.00、または hard 条件不成立。
- undetermined: 上のどちらでもない場合、およびゲート・precheck・env_info・run 数が成立しない場合。
[判定（ガードセル）]
