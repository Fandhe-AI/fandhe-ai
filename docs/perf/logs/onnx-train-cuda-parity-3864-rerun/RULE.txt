# ---- 記録 ----

  TRAIN_PARITY 行を集計する。1 行に case・family・quantity・arm・route・judge・total・fail_count・max_abs_diff・mean_abs_diff・max_rel_err・verdict が入る。
  --nocapture では最初の TRAIN_PARITY 記録が「test <名前> ... 」と同じ行に出るので、行頭に限らず数える（元の回の README と同じ数え方）。
  onnx 族は 2 ケース × 6 量で 12 行のはず。12 行でない、または verdict=pass 以外の行があれば、pass と書かず所有者へ報告する（pass を緩めない）。
  summary.tsv の verdict は exit code と test result 行で決まり、非 0 終了はすべて fail と書かれる（雛形は TRAIN_PARITY 行を見ない）。
  非 0 終了のときの fail／undetermined は、上の fail・undetermined の定義でログの TRAIN_PARITY 行と panic メッセージから決め、README に書く
masking: ホスト名・ユーザー名・ホームのパスを <cuda-node>／<user>／<home> へ置換する（前後が識別子文字でない場合のみ）。

integrity: 保存したファイル群の SHA256SUMS を作り、env_info.txt の script_sha256・rev_stamp と合わせて実行と提出物の対応を検証する
