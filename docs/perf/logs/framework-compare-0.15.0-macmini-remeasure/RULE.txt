  (4) 比較相手の venv の前提（0.14.0 の収録 freeze と byte 一致）と、計測後の freeze 収録・cmp
判定式・閾値（1 超が 1 位、0.90 以上が僅差）・N=5・相手の parity fail は判定不能・判定側の parity 不合格は fail-closed・期待行数・tolerance・baseline は 0.14.0 と同一。

既定設定（0.14.0 の「SME OFF・Graph capture OFF」からの書き換え。根拠は v0.15.0 タグ 22a475e2d のコード）:
  環境変数で既定を変えずに測る。0.15.0 の既定は次のとおり。
  ・SME_PRODUCTION_ENABLED（crates/backend-cpu/src/gemm_blis/mod.rs）と SME_SMALL_SCHED_ENABLED（同 sme_small_sched.rs）は true。aarch64 で効き、Mac mini M4 は SME 経路を使う（GB10 は SME 非搭載で NEON のまま）。
  ・推論スコープ jpw1（INFER_SCOPE_JPW1_ENABLED。同 infer_scope.rs）は aarch64 Linux（GB10）だけ。Mac mini では効かない。
  ・CUDA 推論 Graph は既定 ON（INFER_GRAPH_DEFAULT_ENABLED。crates/backend-cuda/src/graph.rs）。既定のストリームが created stream になり、学習にも効く。Mac mini では効かない。
  ・Metal の STEEL_LARGE_N_ENABLED（crates/backend-metal/src/tile.rs）は true。M4Base の正方 1024／2048／4096 に効く。
  環境変数の検査: 各 run の前に FANDHE_AI_* と RAYON_NUM_THREADS が 1 つも設定されていないことをランナーが確かめ（scripts/env_guard.sh）、設定があれば名前だけを出して rc 3 で止める。
  結果（なし）は run ごとの env_guard.txt と、系列の前後の env/env_info_*.txt に残る。
  N = 5。

venv の前提（0.14.0 と同じ中身であること。系列の前の事前検査）:
  scripts/venv_preflight.sh macmini <venv の親ディレクトリ> を実行し、使う venv の uv pip freeze が 0.14.0 の収録

  不在や不一致なら測らず止まる（作り直しは別承認）。計測後にも freeze を収録し、collect.sh が 0.14.0 の収録と cmp する（env/freeze-cmp.txt。不一致は rc 5 で所有者へ報告）。

判定（0.14.0 から不変）: 比 = 同一 run 内の「有効な相手のうち最速 / fandhe-ai reuse」の 5 run 中央値（推論はスループット比。同じ式）。
  比 > 1 で 1 位、>= 0.90 で僅差、それ未満は負け。相手側の parity_fail_count > 0 の行は判定不能（その相手を順位・最速に含めない）。
  判定側（fandhe-ai reuse）の要素検証（parity_fail_count）が 1 件でも不合格なら、判定不能にせず生成を停止する（fail-closed）。
  欠損 run・有効な相手の不在も生成停止。負けの「N 位」と相手名は 5 run 中央値で数える。tolerance・baseline は変えない。
  判定一覧の生成器・検査器（gen_0150.py・check_0150.py）は #4179 の範囲で、本計測の範囲外。判定規則は上の式のとおりで、変更しない。

  ・各ラウンドの前: 他ジョブが CLEAN かつ load1 < 3.0 になるまで 30 秒間隔・最大 30 分待つ。超えたら GATE-TIMEOUT で打ち切る。

  ・各ラウンドの後: 1 回確かめ、FOREIGN（またはゲート自身の失敗）ならそのラウンドを無効にして系列を打ち切る。
  ・数値が取れない・ゲート自身の失敗は GATE-INVALID で打ち切る。
  ・ゲートの中身は変えない。docs/perf/logs/macmini-foreign-job-gate/foreign_job_gate.py（G1〜G4）を ab_foreign_gate.sh 経由で呼ぶ（scripts/foreign_gate_wrapper.sh が sha256 を検査してから呼ぶ）。
