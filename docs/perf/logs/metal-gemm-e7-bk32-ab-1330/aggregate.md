## 表記注

5 run 中央値）と「両群中央値の比」（base 5 run 中央値 ÷ head 5 run 中央値）は別指標。
判定には**run 別比の中央値と符号一貫性**を使う（PR #1389 の codex-review 指摘を踏襲）。
base／head の絶対値列は各 `kernel_gpu_run<k>.log` の run 順（run1〜run5）で同一ファイル
内の対応行から抽出したもの（PR #1392 codex-review 指摘を踏まえ再対応付け）。

## 妥当性帯チェック

`docs/perf/metal-gemm-reuse-phase-breakdown.md` §11.5 分母（N=1024 1.0267 / 2048 3.1849 /
4096 13.7051 ms。`dispatch_auto` 経由の `kernel_gpu`）と B 系列 base 列（本番選択構成の
`kernel_gpu`。AGENTS.md「5 回計測中央値」規約に沿い 5 run の中央値で突合する）を比較する。

`kernel_gpu_production_select_run*.log` の base 列 5 run（PR #1392 codex-review 指摘を
踏まえ再集計）:

- N=1024: 1.0245（run1・外れ値）／0.2238／0.4355／0.2240／0.2243 → 中央値 **0.2243 ms**
- N=2048: 1.5960／1.5965／1.6006／1.6100／1.6082 → 中央値 **1.6006 ms**
- N=4096: 13.7201／13.6939／13.7434／13.7372／14.6055 → 中央値 **13.7372 ms**

中央値で突合すると、N=2048/4096 は分母（3.1849 ms／13.7051 ms）と概ね同オーダーで整合
する一方、**N=1024 は分母 1.0267 ms に対し本実測の中央値 0.2243 ms と約 4.6 倍の乖離が
あり、run1 のみを見て「概ね整合」と誤判定していた点を訂正する**。N=1024 run1（1.0245 ms）
はこの base 列内でも他 4 run（0.2238〜0.4355 ms）から外れた外れ値であり、中央値には
採用していない。乖離の要因は分母（`metal-gemm-reuse-phase-breakdown.md` §11.5。reuse
フェーズ境界込みの計測）と本ハーネス（カーネル純境界のみ計測）の計測境界差、および
本番選択構成自体が #1039 実測時点から変わりうる点（N=1024 は `select_with_occupancy`
縮退構成 `(64,32,8,4,1)` を観測）が考えられるが、機構レベルの追加切り分けは本イシューの
範囲外とし、分母は置換せず参考記録に留める。この乖離は B 系列自体（同一実行内で base・
head を対応付けて計算する run別比）の妥当性・採否判断（REJECT）には影響しない。

## 全 5 run の共有負荷記録

実行時 load average は概ね 2.7〜5 台（1 分値）で推移し、他イシューの並列実行による共有
負荷下での計測（env_info.txt 参照）。ただし符号一貫性が全区間・全 N で 100%（A 系列
15/15・B 系列 20/20）のため、共有負荷のノイズが結論（REJECT）を覆す余地はないと判断する。
