3. 負荷ゲート
  - 継承スクリプトの登録値のまま使う (CPU の B1・B2 は load1 < 8.0、CUDA の B3・B4・B6 は専有ゲート
    〈load1 < 1.0 かつ GPU 0%〉)。GB10 用の外側ゲートは追加しない。
  - ビルドとの並走を禁じる。RAYON_NUM_THREADS は unset。affinity の固定はしない。

4. 2 機体判定 (2104 / 2102) での GB10 の位置づけ
  - 機体ごとの条件 (セル別 5 round 中央値 ratio <= 1.00・checksum 完全一致・5/5 round 一貫) は GB10 にそのまま適用する。
  - REJECT 条件 (いずれかの機体で 5/5 round 一貫して後退) を GB10 で満たせば単機で REJECT 確定。
  - ADOPT は両機体の成立が要る。GB10 だけが成立した場合は
    「GB10 機体判定: ADOPT 条件成立 (総合は Mac mini〈#3184〉待ち)」と書き、ADOPT とは書かない。

5. B2 の固定事項
  - T_gb10 は 2101 の決定規則を GB10 の 5 演算に適用して機械的に計算する (optin-ab-gb10-3190/aggregate_sweep_single.py。
    継承の aggregate_sweep.py は --m4max と --gb10 の両方を必須とするため、関数を再利用する単機補助を使う)。
  - T_gb10 <= 640 なら REJECT で Stage 1 へ進まない。Stage 0 の checksum が 1 件でも合わなければ FAIL。
  - on-reduction-gb10.patch の @T@ は Stage 0 確定後に記入する (規則の緩和ではない)。最終 T = min(T_macmini, T_gb10)。
  - MSE backward は適用外 (2102 の除外節)。

6. B3 の固定事項

    undetermined を 1 回記録して終える (やり直しのループはしない)。
  - 既定の反転はイベント追跡の無効化を含むため別 PR。

7. B4 の固定事項

    原因を記録する (一部 run の差し替えはしない)。RUN_NSYS=1 は nsys があれば使う (判定には使わない)。

8. B5 (新規登録。cuda-gemm-boundary-predicate-ab.md の判断基準を厳しくする方向で形式化)
  - base = 本規則を固定したコミット、head = base + on-boundary-predicate.patch (kernels_mma.rs の MMA_F16 のみ。
    ソースの証跡テストは事前計算後の形へ合わせ、境界検査があることの機械検証を保つ)。
  - 前提ゲート (順序固定。1 件でも外れたら性能判定へ進まない):
    (a) cargo test -p fandhe-ai-backend-cuda --release -- --ignored の parity 系を base・head の両方で実行し、
        head が base から後退していない (base で既に FAIL のものは base でも FAIL と示して区別)。
    (b) レジスタ数・local memory 使用量 (NVRTC の ptxas -v 相当) を base/head で記録。
        local memory が増える、またはスピルが出たら前提不成立として undetermined。
  - 計測: gemm_mma_bench を腕ごとに 5 プロセス独立で起動し、round ごとに起動順を反転。専有ゲートは load1 < 1.0 かつ GPU 0%。
  - 判定: 全形状で head の 5 run 中央値 TFLOPS >= base、かつ 1 形状以上で 5/5 run 一貫して改善 -> 採用候補。
    いずれかの形状で 5/5 run 一貫して後退 -> 不採用。それ以外 -> undetermined。採用しても main のカーネルは変えない。
  - REQ-8: 検査を前倒しするだけで省かない。クランプ済みアドレス計算は変えない。境界検査を省く変種は採らない。
  - 打ち切り: patch が前提ゲート (a) を通らない、または実装が時間内に終わらないときは「未実施 (undetermined)」と書き、推定で埋めない。

10. 運用
  - run の差し替え・追加・セルの除外は禁止。再実行は別 label で行い旧系列も残す。
  - 欠損・round 数 != 5・非有限値・checksum 不一致は FAIL / undetermined (fail-closed)。
  - 実機に届かない・完走しない系列は推定で埋めず undetermined (未実測) と書く。
  - マスク規則: ホスト名は masked、$HOME は <home>、ユーザー名・絶対パスは除く。
  - 2 時間を超える場合は CPU 系 (B1 -> B2) と CUDA 系 (B3 -> B4 -> B6 -> B5) の 2 セッションに分ける。
  - 定数は main で変えない。計測前にこの規則を単独でコミットして固定する。
