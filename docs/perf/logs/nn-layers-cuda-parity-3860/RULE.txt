# ---- run 数 ----
runs: 各コマンド 1 回。時間の計測ではないので中央値は取らない。fail の後に再実行して pass に置き換えない。
  再実行するなら RULE.txt を登録し直す

# ---- 記録 ----
record: 実行ログ全文（--nocapture）を保存する。各ログ末尾に rc=<終了コード>。summary.tsv に exit code・running 件数・test result 行・判定を書く
masking: ホスト名・ユーザー名・ホームのパスを <cuda-node>／<user>／<home> へ置換する（前後が識別子文字でない場合のみ）。
  漏れたら記録を捨てて取り直す（fail-closed）。回収ログは手で編集しない
integrity: 保存したファイル群の SHA256SUMS を作り、env_info.txt の script_sha256・rev_stamp と合わせて実行と提出物の対応を検証する

# ---- fail の扱い ----
fail_handling: fail が出ても tolerance・判定方式・入力・テストコードを変えない。panic メッセージの値（fail_count・max_abs_diff・
  max_rel_err、bit 不一致の位置など）をそのまま引用して事実を記録し、README と PR に「要対応」と書く。原因を推測で結論づけない。
  起票と baseline 化は所有者の承認を得てから行う
