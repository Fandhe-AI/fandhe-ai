## 妥当性帯チェック（`docs/perf/metal-gemm-reuse-phase-breakdown.md` §11.5 分母との突合）

同ファイル §11.5 の `kernel_gpu` 分母（本番選択構成。N=1024 1.0267 ms・N=2048 3.1849 ms・N=4096
13.7051 ms）と、本計測の B 系列 base（production_select）絶対値中央値（N=1024 0.3769 ms・
N=2048 1.6105 ms・N=4096 15.8216 ms）を突合する。N=4096 は近い値（15.82 対 13.71 ms・約 1.15
倍）だが、N=1024/2048 は既知の乖離（§9.4「既知の乖離。約 4.6 倍」に整合する方向。本計測は
warmup 20／測定 20 の交互測定プロトコルであり単発 5 プロセス起動の §11.5 計測とは条件が異なる
ため、絶対値の差自体は #1332 のスコープ外・既知の事象として扱う）。**採否判断は base/head の
同一 run 内 run 別比〈`head_over_base_kernel_gpu`〉の符号一貫性で行うため、base 絶対値の
プロトコル間差は判断そのものへは影響しない**（base・head とも同一プロトコル・同一 run 内で
測定しているため）。

## 判定

- A 系列: `[10]` は `[0]`（構造上の直接対応）に対し全 N で 1.65〜2.40 倍後退、`[3]`（イシュー
  文言の参考ペア）に対し全 N で 10.5〜14.2 倍後退。いずれも 5/5 run 符号一貫。
- B 系列（結線判断の唯一の根拠）: `[10]` は本番選択構成に対し N=512〜4096 の全帯域で
  9.7〜13.0 倍後退。20/20 run 符号一貫（5 run × 4 N すべて後退方向）。
- 採否判定基準（§16.5 に転記）に照らし、B 系列は「REJECT: 当該 N で後退方向（比 ≥ 1.0）が
  5/5 符号一貫」に該当する N=512/1024/2048/4096 すべてで成立。**組み込み不可（REJECT）**。
  `tile.rs`／`gemm.rs`／`shaders/gemm.metal` は無変更のまま維持する。
