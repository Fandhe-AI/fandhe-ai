[読み方の規則（分類であり判定ではない。事後に変えない）]
- 腕 a の代表値 = 5 run の median_s の中央値。比 rho(a) = 代表値(a) / 代表値(aa0)。round 内比 rho_r(a) = 同一 round 内の a / aa0。
- ノイズ幅 N = max(|rho(aa1) - 1|, max_r |rho_r(aa1) - 1|)。Delta_after = rho(excl1) - 1。
- (i) |Delta_after| <= N: 「差は A/A と同程度。コードに原因は見つからない」→ 停止して所有者へ報告。
- (ii) Delta_after > N のとき、各 revert 腕 R について:
  - 原因候補: |rho(R) - 1| <= N かつ rho_r(R) / rho_r(excl1) < 1 が 4/5 round 以上。
  - 無関係: |rho(R) / rho(excl1) - 1| <= N。
  - それ以外: 部分／不明。
- (iii) Delta_after < -N: 「after が速い」。停止して報告。
- excl0-rebuild または rv-graphlock（既定 OFF の経路外）が |rho - 1| > N で動いた場合は「ビルド・配置の影響あり」と併記する。
- 結論の対応表: rv-kindlookup が原因候補 → resolved_stream_kind の mutex 等の本体コスト。rv-scopecall だけが原因候補（rv-kindlookup は無関係）→ 呼び出し・スコープ型の扱い自体のコスト。OFF 経路の腕がどれも原因候補にならず対照腕が動く → 配置・ビルド起因（コード原因なし）→ 停止。どれにも当てはまらない → 停止・報告（推定で埋めない）。
