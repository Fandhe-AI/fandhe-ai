[裾の帰属（AC2。全腕×全 run）]
- 裾 = iter_total（G は wall）が、その腕×run の中央値の 1.25 倍を超える反復。それ以外を本体とする。
- 対象 run: 裾が 10 反復（2%）以上ある腕×run（本体が空でないこと）。
- 区間 P: R は predict_resident・host_copy・checksum、D と Don は provider_select・tape_new・snapshot・chain・host_copy・checksum、
  G は upload・encode・commit_wait・gpu_busy・commit_wait-gpu_busy・download。
  Δ_P = median(P|裾) - median(P|本体)、Δ_total = median(iter_total|裾) - median(iter_total|本体)、比 = Δ_P / Δ_total。
- 帰属: 対象 run の過半数で比 >= 0.5 になった区間。該当なしなら「特定できなかった」と記す。
- 追加判定「GPU 実行時間は不変」（G）: 対象 run の過半数で |Δ gpu_busy| / median(gpu_busy|本体) < 5%。
- gpu_busy が null の反復は区間側だけでなく Δ_total の標本からも外し、件数を報告する。
- 帰属は commit_wait - gpu_busy（ホスト側の完了待ち）までとする。commit_wait を GPUStartTime より前と GPUEndTime より後に
  さらに分けるには context.rs への cfg(test) アクセサが要り、ライブラリのファイルを変えるため本ラウンドの対象外とする。
- 記録のみ: 0.4 ms を超える反復の割合を腕×run ごとに出す。RULE.txt の 5% 規則による多峰判定も併記する。

[run 全体の低性能状態（H2）]
- GPU の代理指標: HEAD-G の gpu_busy の run 中央値。CPU の代理指標: HEAD-R の checksum 区間の run 中央値（v0110-R も記録）。
- 「低性能 run」: その指標が、5 run の中央値の 1.5 倍以上の run。GPU と CPU の両方で低性能の run を
  「システム全体の低性能状態」とする。起動順・経過秒数・load・上位プロセスは並べて記録のみ（判定に使わない）。
