判定（REQ-2 統一複合判定: 相対誤差 1e-3 未満 または 絶対誤差 1e-5 未満。tolerance 定数・baseline は不変）:
  pass: exit 0 かつ "running 1 test" かつ "test result: ok. 1 passed; 0 failed" の 3 つが揃うこと。
  fail: テストの失敗。tape_for(Device::Cuda(0)) の失敗・Unsupported・panic を含む。
    CPU との不一致は判定不能にせず通常の parity 失敗として扱う。
  undetermined: ノード到達不能、ビルド不能、timeout（exit 124）、--list で選ばれた件数が 1 でない。pass に数えない。
  時間計測ではないので中央値は取らない。テストごとの pass／fail の件数で記録する。
