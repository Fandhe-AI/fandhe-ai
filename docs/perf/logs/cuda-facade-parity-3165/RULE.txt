判定（REQ-2 統一複合判定: 相対誤差 1e-3 未満 または 絶対誤差 1e-5 未満。tolerance 定数・baseline は不変）:
  pass: exit 0 かつ "running 1 test" かつ "test result: ok. 1 passed; 0 failed"。
  fail: 1 件以上のテスト失敗（パニックを含む）。CUDA と CPU は自前バックエンド同士の比較なので判定不能にせず
    通常の parity 失敗として扱う。
  undetermined: timeout（exit 124）、--list で選ばれた件数が 1 でない、ビルド不能、ノード到達不能。
  時間計測ではないので中央値は取らない。群ごと・テストごとの pass／fail の件数で記録する。
