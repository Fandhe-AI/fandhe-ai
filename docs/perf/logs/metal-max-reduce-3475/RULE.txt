判定:
  pass: exit 0 かつ "running 1 test" かつ "test result: ok. 1 passed; 0 failed"。
  fail: テストの失敗・panic・Unsupported・tape_for(Device::Metal) の失敗。Metal と CPU は自前バックエンド同士の
    比較なので判定不能にせず通常の失敗として扱う。bit 一致の fail を REQ-2 pass へ読み替えない。
  undetermined: ノード到達不能・ビルド不能・timeout（rc 142）・--list で選ばれた件数が 1 でない・並走プロセスが消えない・
    マスク後のテスト名残存検査の失敗。undetermined は pass と見なさない。
  時間計測ではないので中央値は取らない。pass／fail／undetermined の件数で記録する。
