## 計測プロトコル
- before（legacy）腕: base コミット `fddca17`（origin/main。#1437 マージ直後）の
  `scripts/bench/framework-compare/bench-fandhe` ソース（旧 `host-view-readout` cargo
  feature・既定 OFF＝legacy `to_tensor()+to_vec()` 経路）
- after（default）腕: 本 PR（イシュー #1438）HEAD の bench-fandhe ソース（借用ビュー
  readout が既定経路・cargo feature 撤去済み）
- 両腕とも `GEMM_GATE_PATCH_FACADE_PATH` で本 PR HEAD の同一 `crates/facade` ツリーを
  path patch 指定（facade ソースを揃え、readout 経路の差だけを分離する。#1337/#1437 の
  「off 腕 registry・on 腕 path」という facade ソース不一致の反省を踏まえる）
- 各腕は同一ノード内で連続実行（before → after の順）。CUDA・Metal・CPU(dgx)・CPU(m4max)
  は互いに独立したノード／リソースのため並列実行した
- 計測後 `git diff --exit-code scripts/bench/framework-compare/Cargo.lock` を確認し、
  path patch による Cargo.lock の意図しない書き換えがないことを検証した（差分なし）
