[分類規則（分類であり判定ではない。事後に変えない）]
- 腕 a の代表値 = 5 run の median_s の中央値。比 rho(a) = 代表値(a) / 代表値(aa0)。round 内比 rho_r(a) = 同じ round の a の median_s / aa0 の median_s。
- ノイズ幅 N = max(|rho(aa1) - 1|, max_r |rho_r(aa1) - 1|)。
- D1 = rho(ch1) - 1（B1 での chain/reuse）。D2 = rho(rb1) / rho(rb0) - 1（B2 での chain/reuse）。P = |rho(rb0) - 1|（reuse の配置感度）。
- c1 = rho_r(ch1) > 1 の round 数。c2 = 同じ round の rb1 / rb0 > 1 の round 数。
- (i) ノイズ幅内: |D1| <= N かつ |D2| <= N。
- (ii) チェーン化の後退: D1 > N かつ D2 > N かつ c1 >= 4 かつ c2 >= 4。→ CPU train の内訳（GEMM・autodiff・チェーン化の固定費）を測る腕を、別名の規則 DIAG-breakdown.txt で計測前に登録してから測る。
- (iii) 配置の影響: (i)・(ii)・(iv) に当たらず、D1 と D2 の一方だけが N を超える、または両方が N を超えて符号が逆、かつ P > N。
- (iv) chain が速い: D1 < -N かつ D2 < -N。報告して止める。
- (v) 判定不能: 上のどれにも当たらない。報告して止める（推定で埋めない）。
- 判定の順序: (i)、(iv)、(ii)、(iii)、(v)。境界（等号）は (i) 側（<= N）に倒す。
- 併記（分類は変えない）: B0 の o1/o0 - 1（#3257 時点のコードでの chain/reuse）と、N・D1 との関係。N が観測差より大きいときに (i) になるのは規則上の帰結であり、正当な結果として記録する。round 数の追加・閾値の変更で白黒を付けにいかない。
