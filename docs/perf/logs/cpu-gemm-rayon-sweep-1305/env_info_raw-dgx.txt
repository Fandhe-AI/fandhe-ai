MAXMHZ が 2 群に分かれる（2808.0000 MHz と 3900.0000 MHz）。3900 MHz 群の
CPU id は `5,6,7,8,9,15,16,17,18,19`（計 10）・2808 MHz 群は
`0,1,2,3,4,10,11,12,13,14`（計 10）。

## /sys/.../regs/identification/midr_el1（実測。partnum で機種確認）

```
cpu0: 0x00000000410fd871
cpu5: 0x00000000410fd851
```

MIDR_EL1 のビット構成は `[31:24] implementer・[23:20] variant・[19:16] arch・
[15:4] partnum・[3:0] revision`（ARM Architecture Reference Manual）。

- cpu0: implementer=0x41（ARM）・partnum=0xd87 → **Cortex-A725**（little）
- cpu5: implementer=0x41（ARM）・partnum=0xd85 → **Cortex-X925**（big）

MAXMHZ 群と midr partnum が一致（3900 MHz 群 = X925 = big・2808 MHz 群 =
A725 = little）。DGX Spark GB10 の公称構成（Cortex-X925 ×10 + Cortex-A725 ×10）
とも一致。

## 導出した taskset マスク

- 大コア（X925）: `taskset -c 5-9,15-19`
- 小コア（A725）: `taskset -c 0-4,10-14`

## which taskset

```
/usr/bin/taskset
```
