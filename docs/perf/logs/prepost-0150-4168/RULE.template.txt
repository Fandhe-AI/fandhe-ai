[比・区分]
- 腕ごとに、run ごとに「同じ run の有効な相手（parity_fail_count == 0 の fresh 行）の最速 median_s ÷ その腕の fandhe reuse median_s」を求め、5 run の中央値で区分する（1 を超えれば 1 位、0.90 以上なら僅差、それ未満は負け。推論は同じ式でスループット比と一致する）。
- 0.15.0 の見込み = after 腕の比と区分。0.15.0 の公開版には Phase 5 以降の変更が入りうる。勝敗の正は Phase 6（#4177〜#4179）の測り直し。
- 腕比（参考）: median(after の reuse median_s) ÷ median(before の同じ値) と run ごとの値。合格ラインは置かない。27 セルで 5/5 run 一貫の後退が出たら所有者への報告事項として記録し、自律的な revert・再計測による差し替えはしない。
- ノイズ帯 NB-RANGE5・確定条件 NB-SEP（#4142）は所有者未承認のため、帯（after の run 別の最小〜最大）を記録のみとし、判定に使わない。「承認済み」とは書かない。

[hard 条件]
- 同じ腕の 5 run すべてで checksum・parity_total・parity_fail_count・parity_max_abs_err・parity_max_rel_err・parity_scaled_abs_bound・parity_scaled_abs_rescued が完全に一致する（reuse・fresh 両方。train／infer は checksum）。不一致は「正しさの失敗」として所有者へ報告する。tolerance・baseline は変えない。
- 腕の間（before と after）の checksum の差はライブラリのコードが違うため即失敗にせず、セル単位で「差あり」と記録して所有者へ報告する。
- 判定側（fandhe）の parity_fail_count > 0 が 1 件でもあれば停止する（終了コード 4）。相手の parity fail はその相手を除外する。
- 終了コード: 0 = 全セル判定可能、2 = undetermined あり、3 = 同じ腕の中の hard 不一致（優先）、4 = 判定側の parity 停止。
