## #1103 §4.2 カーネル純境界との突合（妥当性帯チェック）

#1103 §4.2 の N=4096 カーネル純境界は 9.76〜9.91 TFLOPS（2·4096³/9.76e12
≈ 14.08 ms 〜 2·4096³/9.91e12 ≈ 13.87 ms の帯）。本計測の kernel_gpu 中央値
13.7051 ms（10.028 TFLOPS）はこの帯よりわずかに高速側（帯下限 13.87 ms比
で約 1.2% 短い）だが、計測プロトコル（#1103 は `gemm_bench` 系の独立ベンチ、
本計測は `synchronize_with_gpu_timestamps` による GPU タイムスタンプ）が
異なるため「大きく外れる」水準ではないと判断し、そのまま採用した。

## #1189 §4/§7 とのセッション間ドリフト検査

#1189 §4 の N=4096 `commit_wait` 中央値は 15.7457 ms。本計測の
commit_wait 中央値 15.7892 ms との乖離は約 0.28% で 10% 閾値を大きく
下回るため、再アンカー（Layer A 再計測）は実施しなかった。
