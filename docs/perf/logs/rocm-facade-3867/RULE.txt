# ---- 判定（事前宣言）----
judgment: 各比較は compare(...).passes()（fail_count=0）。テストの assert のとおり
pass: コマンドが exit 0 で、出力に「running 1 test」と「test result: ok. 1 passed; 0 failed」があること
fail: 上記以外の非 0 終了のうち undetermined に当たらないもの（「REQ-2 統一複合判定に失敗」、列挙の assert、expect の panic を含む）
undetermined: ノードに届かない、ビルドできない、timeout、--list の不一致（": test" で終わる行がちょうど 1 件でない）。pass として扱わない
completion: 4 本すべて pass で #3867 の完了とする。1 本でも fail・undetermined なら Closes にせず Refs にとどめ、未実測・fail の理由を書く
