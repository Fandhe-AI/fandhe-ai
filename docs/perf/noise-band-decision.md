## 1. 背景

- 0.14.0 のスコアボードは、Mac mini の僅差 3 セル（M-MTL-G1024 0.98×・M-MTL-G2048 0.94×・M-MTL-TRN 0.96×）の「ノイズ帯」を「未算出（対照系列なし）」とし、判定一覧の tally 行は `noise na` である。
- 過去の「ノイズ帯」は 0.10.0〜0.11.0 の系列 A（ゲートなし）と系列 B（ゲートあり）で勝敗区分が反転した行を指していた。0.13.0 以降の RULE は系列 A を置かない（`framework-compare-0.14.0-macmini-remeasure/RULE.txt` の「系列」節）ため、この定義では算出できない。
- このままでは Phase 3 の改善が「1 位に変わった」のか「揺れの中」なのかを判定できない。算出方法を先に決めて事前登録する。
- 判定の既存規則（比 > 1 で 1 位、>= 0.90 で僅差、それ未満は負け。比は同一 run 内の「有効な相手の最速 ÷ fandhe-ai reuse」の 5 run 中央値）は変えない。0.14.0 の判定一覧の `noise na` も歴史的事実として維持する。

## 2. 候補の比較

| 名前 | 内容 | 追加計測 | N=5 での情報量 | 判断 |
|------|------|----------|----------------|------|
| **NB-RANGE5**（推奨） | セルごとの run 別対戦相手比の最小〜最大 | 不要 | 5 run の揺れそのもの | 採用案 |
| NB-IQR | fandhe-ai reuse の iter 内 q1/q3 から作る比の帯（run 間の中央値） | 不要 | iter 内の揺れ（run 間とは別の層） | 記録のみ・判定に使わない |
| ブートストラップ区間 | run 別比の再標本中央値の 90% 区間 | 不要 | N=5 では最小〜最大とほぼ一致 | 却下（独自の情報が増えない） |
| A/A 対照 | 同一バイナリを 2 腕で流し、腕間の比の揺れを帯とする | 要（実機計測） | 腕間の系統差を直接見られる | 本 Phase では不採用。各 A/B の設計側で採否を判断（§6） |
| 系列 A/B の区分反転（旧定義） | ゲートなし／ありで区分が反転した行 | 要（系列 A） | — | 却下（0.13.0 以降は系列 A を置かない） |

## 3. 0.14.0 への試算

比の式は `gen_0140.py::paired_ratio`（Mac mini は `judge_macmini_0140.py` の同名関数）と同じ。出力は `docs/perf/logs/noise-band-4142/noise_band_0140_{macmini,gb10}.tsv`。

### 3.1 Mac mini の僅差 3 セル

| セル | run 別比（run1〜run5） | 中央値 | NB-RANGE5（最小〜最大） | 境界 1.0／0.90 をまたぐか | NB-IQR（参考） |
|------|------------------------|--------|-------------------------|---------------------------|----------------|
| M-MTL-G1024（gemm Metal N=1024・vs candle） | 0.985 0.990 1.119 0.971 0.966 | 0.985 | 0.966〜1.119 | **1.0 をまたぐ**（ノイズ帯） | 0.974〜1.005 |
| M-MTL-G2048（gemm Metal N=2048・vs candle） | 0.939 0.938 0.938 0.939 0.938 | 0.938 | 0.938〜0.939 | またがない（安定した僅差） | 0.936〜0.940 |
| M-MTL-TRN（train Metal・vs pytorch） | 0.959 0.962 0.953 0.986 0.963 | 0.962 | 0.953〜0.986 | またがない（安定した僅差） | 0.951〜0.979 |

読み方:

- G1024 は 5 run 中 4 run が 1.0 未満で、run3 だけ 1.119 と離れる。区分（僅差）は揺れの中にあり、1 位との境は確定していない。
- G2048 は 5 run がほぼ同値（0.938〜0.939）で、僅差の区分は安定している。1 位に変えるには約 6.6% の改善が要る（1.0 ÷ 0.938）。
- TRN は run4 の 0.986 が最大で、帯は 1.0 に届かない。僅差で安定している。1 位に変えるには、中央値 0.962 から約 4% の改善が要る（最良の run4 でも 0.986 のため約 1.4%）。

### 3.2 全 27 セルへの適用（参考）

NB-RANGE5 が 1.0 をまたぐセルは 27 セル中 4 件、0.90 をまたぐセルは 0 件だった。

| 機体 | セル | 0.14.0 の区分 | 中央値 | NB-RANGE5 |
|------|------|---------------|--------|-----------|
| Mac mini | gemm Metal N=512 | 1 位 | 1.074 | 0.952〜1.489 |
| Mac mini | gemm Metal N=1024 | 僅差 | 0.985 | 0.966〜1.119 |
| Mac mini | infer Metal | 1 位 | 1.020 | 0.992〜1.035 |

- 0.14.0 で「1 位」と表示された 3 セル（Mac mini の gemm Metal N=512・infer Metal、GB10 の gemm CPU N=512）は、NB-RANGE5 では 1.0 をまたぐため「1 位は揺れの中」と読む。判定一覧の区分そのものは変えない。
- 走査対象は Mac mini 13 セルと GB10 14 セル。全セルの値は TSV を参照する。

## 4. 推奨案（RULE へ貼る文面）

```text
ノイズ帯 := NB-RANGE5（#4142 の決定記録 docs/perf/noise-band-decision.md）
  セルごとに、同一 run 内の対戦相手比（paired_ratio が返す run 別の値）の最小〜最大を帯とする。追加計測はしない。
  帯が区分境界 1.0（1 位／僅差）または 0.90（僅差／負け）を含む（境界ちょうども含む）セルを「ノイズ帯」とし、
  そのセルの区分は揺れの中で決まっており確定とは言わない。

確定条件 := NB-SEP（A/B で「1 位に変わった」と言える条件）
  変更後腕の 5 run すべてで比 > 1.0、かつ 変更後腕の最小 > 変更前腕の最大。
  変更前腕は同一セッションで測る（日をまたいだ過去値を変更前腕に使わない）。
  どちらかを満たさなければ「1 位に変わった」とは書かず、「改善傾向・確定せず」と書く。

記録のみ（判定に使わない）:
  NB-IQR（iter 内 q1/q3 から作る比の帯）、前版比（日またぎのドリフトの目安）。
```

- 区分が「負け→僅差」に変わる場合の確定条件は、境界 0.90 に読み替えて同じ形を使う（変更後腕の 5 run すべて 0.90 以上、かつ変更後腕の最小 > 変更前腕の最大）。
- 日またぎのドリフトの目安として、0.13.0 → 0.14.0 の fandhe-ai 中央値比は Mac mini の 13 セルで 0.99〜1.03 だった（`gen_0140_macmini.out` の「0.13.0 比」）。NB-SEP は同一セッション内の変更前腕を使うので、この日またぎのドリフトは判定に入らない。

## 5. 限界

- N=5・単一機体・単一日の揺れである。帯が境界をまたいでいなくても「確定」の保証ではない（NB-RANGE5 はノイズ帯でないことの十分条件ではなく、ノイズ帯を検出する条件である）。
- 5 run の最小〜最大は N が増えるほど広がる方向にしか動かないため、N の異なる系列同士（N=5 と N=10 など）の帯は比較しない。
- run 間は各 run 前の load1 ゲート（< 3.0）を通した系列 B であり、ゲートなしの条件の揺れは含まない。ゲートなしの条件での運用値は別の問題として扱う。
- iter 内 IQR（NB-IQR）は run 内の揺れで、系統差（腕間の差）を含まない。参考表示にとどめる。
- 変更前腕と変更後腕を同一セッションで測る NB-SEP は、機体の状態の揺れを帯に入れるが、腕間の系統差（バイナリ配置の違いなど）は分離できない。この分離には A/A 対照が要る（§6）。

## 6. 所有者の決定（2026-11-10 承認済み）

承認コメント: https://github.com/Fandhe-AI/fandhe-ai/issues/4142#issuecomment-6757497844 （案 A）。判定規則と 0.14.0 の判定一覧の `noise na` は変えない（§1）。本節は承認された内容の記入であり、§2〜§5 の定義・数値は変更していない。

1. **推奨案 NB-RANGE5・NB-SEP の採否**: **採用**（§4 の文面どおり）。
2. **M-MTL-TRN の扱い**: 機械判定（NB-RANGE5 が 1.0 をまたがない）に従い、**「安定した僅差」**として扱う（帯 0.953〜0.986）。
3. **A/A 対照を各 A/B に足すか**: 全 A/B へ一律には足さない。**各 A/B の設計時に、境界（1.0／0.90）をまたぐセルだけ足す**（G1024 のような境界またぎのセル）。
