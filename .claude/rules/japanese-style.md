# 日本語出力スタイル

## 基本

- ユーザーとのやりとり・報告・コミットメッセージ本文・PR 本文・Issue 本文・コード内コメントは日本語で書く
- 技術用語・コード識別子・クレート名は原語のまま使う（無理に訳さない。例: workspace・cfg・trait）

## 表記

- 全角と半角の間にスペースを入れる（例: 「`cudarc` を `=x.y.z` で固定」）
- 箇条書き・表を活用し、冗長な前置き・後置きを避ける
- 数値・実測値は出典（PoC 番号・`file_path:line_number`）を添える

## コミット・PR

- コミットの type/scope（`feat:` 等）は英語、説明文は日本語（conventional-commits.md 参照）
- PR タイトルも同様に「`feat(scope): 日本語説明`」形式とする
